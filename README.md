# 日本語表現学習システム V1

日本語表現を登録し、段階的な間隔で復習するための、個人向けローカル学習システムです。

## プロジェクト概要

日常生活・業務・映像作品などで出会った日本語表現を登録し、中国語の例文だけを見て日本語表現を思い出す「アクティブリコール」形式で復習します。復習結果(正解・不正解)に応じて、システムが次回の復習日と学習段階を自動で管理します。

## 開発目的

- 学習した表現がメモ等に分散し、復習時期を管理しにくいという課題を解決する
- 理解するだけでなく、自分で日本語を想起できるかを確認する機会をつくる
- 苦手な表現(累計誤答回数が多い表現)を優先して出題し、学習効率を高める
- 生成 AI に依存しない学習機能を確立し、将来の拡張の基盤とする

## V1 の対象範囲

- 単一利用者による、Windows PC 上でのローカル利用
- 表現の登録・復習・検索・編集・削除と、学習状況の表示
- 対象外: AI / LLM API との連携、デスクトップアプリ化、認証・複数ユーザー管理

## 主な機能

| 画面 | 機能 |
| --- | --- |
| ホーム | 本日の復習対象件数と登録表現数を表示し、各画面へ移動する |
| 新規登録 | 中国語例文・日本語表現・表現及び中国語意味・備考を登録する(表現 ID は自動採番) |
| 復習 | 本日の復習対象を累計誤答回数の多い順に1件ずつ出題し、「答えを見る」の後に正解・不正解を自己採点する |
| 表現検索 | 表現 ID(完全一致)またはキーワード(部分一致)で登録済みの表現を検索する |
| 編集 | 検索結果から選択した表現の内容を編集する(学習の進捗は変更しない) |
| 削除 | 確認後に表現を削除する(復習画面・表現検索画面から実行可能) |

## 学習ステージの概要

各表現は以下の学習ステージを持ちます。1つの表現を採点できるのは1日1回までです。

| ステージ | 復習間隔 | 次のステージへの条件 | 不正解の場合 |
| --- | --- | --- | --- |
| NEW | 登録の翌日に初回出題 | 初回の採点後に DAILY へ | DAILY へ |
| DAILY | 翌日 | 5回連続正解で WEEKLY へ | DAILY のまま連続正解数を 0 に戻す |
| WEEKLY | 7日後 | 5回連続正解で MONTHLY へ | DAILY へ戻る |
| MONTHLY | 翌月の同日(存在しない日は月末) | 5回連続正解で MASTERED へ | DAILY へ戻る |
| MASTERED | 出題しない(定着済み) | ― | ― |

復習日を過ぎても未実施の表現は、誤答とは扱わず、翌日以降も復習対象として残ります。

## システム構成

開発時と通常利用時で、画面の配信方法が異なります。

```text
開発時:
  ブラウザ → Vite 開発サーバー(localhost:5173) ─ /api/** をプロキシ → Spring Boot(127.0.0.1:8080) → SQLite

通常利用時:
  ブラウザ → Spring Boot(127.0.0.1:8080) ─ 画面(Vue のビルド成果物) + REST API(/api/**) → SQLite
```

- 画面と REST API は同じ場所から配信されるため、CORS の設定は不要です。
- バックエンドはこの PC 内(`127.0.0.1`)でのみ待ち受け、他の PC からはアクセスできません。

```text
japanese-learning-system/
```

フロントエンド固有の内容は [frontend/README.md](frontend/README.md) を参照してください。

## 必要な環境

- Java 17
- Node.js(22.18 以上、または 24.12 以上。フロントエンドのビルド・開発時のみ)

Windows PowerShell で `npm` の実行が制限される場合は、`npm.cmd` を使用してください。

## 開発時の起動方法

バックエンドとフロントエンドの開発サーバーを、それぞれ起動します。

```powershell
# バックエンド
cd backend
.\mvnw.cmd spring-boot:run

# フロントエンド(別のターミナルで実行)
cd frontend
npm.cmd install   # 初回のみ
npm.cmd run dev
```

ブラウザで `http://localhost:5173/` を開きます。

## ビルド手順(通常利用のための準備)

初回、およびソースコードを更新したときに実行します。

### 1. フロントエンドのビルド

```powershell
cd frontend
npm.cmd install   # 初回のみ
npm.cmd run build
```

ビルド結果は `frontend/dist/` に出力されます。

### 2. バックエンドのパッケージ

```powershell
cd backend
.\mvnw.cmd package
```

- バックエンドの自動テストを実行した後、実行用の JAR(`backend/target/japanese-learning-<バージョン>.jar`)を作成します。
- このとき `frontend/dist/` の内容が JAR に取り込まれます。必ず手順1の後に実行してください。
- 自動テストはテスト専用の SQLite DB を使用し、利用中のデータには影響しません。

## V1 通常利用時の起動方法

通常利用の前に、上記の「ビルド手順」(フロントエンドのビルドとバックエンドのパッケージ)を完了しておく必要があります。

開発用のバックエンド(`mvnw.cmd spring-boot:run`)と通常利用時のアプリは、どちらもポート 8080 を使用します。同時には起動できないため、通常利用時は開発用のバックエンドを停止してください。

### start-v1.cmd を使う場合

プロジェクト直下の `start-v1.cmd` をダブルクリック、またはコマンドプロンプトから実行します。

- `start-v1.cmd` は、ビルド・パッケージ済みのアプリを起動するためのものです。ビルド自体は行いません。
- `backend/target` 内の実行用 JAR を自動で検出し、`backend` フォルダで起動します。数秒後に既定のブラウザで `http://localhost:8080/` を開きます。
- ブラウザが先に開いて画面が表示されない場合は、少し待ってから再読み込みしてください。
- 終了するには、起動したウィンドウで Ctrl+C を押すか、ウィンドウを閉じます。
- 実行用 JAR が見つからない場合や、複数見つかった場合は、メッセージを表示して終了します(複数の場合は `mvnw.cmd clean package` で作り直してください)。

### 手動で起動する場合

```powershell
cd backend
java -jar target\japanese-learning-0.0.1-SNAPSHOT.jar   # ファイル名はバージョンにより異なる
```

データベースのパスは `backend` フォルダを基準に解決されるため、必ず `backend` フォルダで起動してください。

## データの保存場所

学習データは次の SQLite ファイルに保存されます(初回起動時に自動作成)。

```text
backend/data/japanese_expression_learning.db
```

このファイルは Git の管理対象外です。バックアップする場合は、システムを停止した状態でファイルをコピーしてください。
