# 日本語表現学習システム フロントエンド

日本語表現学習システム V1 の画面部分(フロントエンド)です。
バックエンド(Spring Boot)の REST API と通信して動作します。

## プロジェクト概要

日常生活・業務・映像作品などで出会った日本語表現を登録し、中国語例文を手がかりに日本語表現を思い出す形式で復習するための、ローカル PC 上で使用する学習システムです。

## V1 の目的

- 日本語表現の登録・検索・編集・削除を行えるようにする
- 復習日になった表現を、中国語例文から日本語表現を思い出す形式で復習できるようにする
- 自己採点の結果に応じて、次回の復習日を段階的に管理する
- 生成 AI に依存せず、ローカル環境だけで学習機能が完結するようにする

## 使用技術

| 分類 | 技術 |
| --- | --- |
| 画面 | Vue 3 |
| 言語 | TypeScript |
| 画面遷移 | Vue Router |
| 開発サーバー・ビルド | Vite |
| バックエンドとの通信 | Spring Boot の REST API(ブラウザ標準の `fetch` で呼び出す) |
| コード品質 | ESLint / Oxlint(静的解析)、Prettier(整形) |

### V1 で採用していないもの

- Pinia(グローバルな状態管理)
- Axios(通信ライブラリ)
- UI フレームワーク(Vuetify、Element Plus など)
- デスクトップアプリ化(V2 で検討)
- AI / LLM API との連携(V3 で検討)

## 主要ディレクトリ構成

```text
frontend/
├─ index.html          画面の土台となる HTML
├─ vite.config.ts      Vite の設定(API のプロキシ設定を含む)
├─ public/             そのまま配信する静的ファイル
└─ src/
   ├─ main.ts          アプリの起動処理
   ├─ App.vue          全画面共通の枠(ヘッダーと画面表示領域)
   ├─ router/          URL と画面の対応(ルーティング)
   ├─ views/           画面(S01～S04)ごとのコンポーネント
   ├─ api/             バックエンド API の呼び出し処理
   └─ assets/          全画面共通のスタイル
```

## 開発環境のセットアップ

### 必要なもの

- Node.js(22.18 以上、または 24.12 以上)
- 起動済みのバックエンド(画面からデータを表示・登録する場合)

### 依存関係のインストール

`frontend` ディレクトリで実行します。

```sh
npm install
```

### Windows PowerShell で `npm` が実行できない場合

実行ポリシー(Execution Policy)の設定により `npm.ps1` の実行が制限される場合があります。その場合は `npm` の代わりに `npm.cmd` を使用してください。

```powershell
npm.cmd install
npm.cmd run dev
```

## 開発サーバーの起動

```sh
npm run dev
```

起動後、ブラウザで `http://localhost:5173/` を開きます。

画面からデータを表示・登録するには、先にバックエンド(`http://127.0.0.1:8080`)を起動しておく必要があります。バックエンドが起動していない場合、画面には接続できない旨のエラーが表示されます。

## 確認・ビルド用のコマンド

| 目的 | コマンド |
| --- | --- |
| 型チェック | `npm run type-check` |
| 静的解析(自動修正あり) | `npm run lint` |
| コード整形 | `npm run format` |
| 本番用ビルド(型チェックを含む) | `npm run build` |

ビルド結果は `dist/` に出力されます。V1 の通常利用時は、この `dist/` をバックエンドの JAR に取り込み、Spring Boot から配信します(手順はプロジェクト直下の `README.md` を参照)。

## バックエンド API との接続方針

開発時は Vite のプロキシ機能を使用して、バックエンドと通信します。

- 画面のコードでは、API を `/api/...` の相対 URL で呼び出します。バックエンドのホスト名やポート番号はコードに書きません。
- 開発サーバーは `/api` で始まるリクエストを `http://127.0.0.1:8080`(Spring Boot)へ転送します(`vite.config.ts` の `server.proxy`)。
- ブラウザからは開発サーバーと同じ場所への通信に見えるため、バックエンド側で CORS の設定は不要です。
- 通常利用時は、画面と API を Spring Boot が同じ場所から配信するため、同様に CORS の設定は不要です。
